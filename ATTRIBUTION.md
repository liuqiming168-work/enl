# Third-party assets

## OpenMoji

The SVG files in `assets/openmoji/` are from [OpenMoji](https://openmoji.org/),
an open-source emoji and icon project by the HfG Schwabisch Gmund design team.

- License: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
- Source repository: <https://github.com/hfg-gmuend/openmoji>
- Files used: the codepoint-named SVG files in `assets/openmoji/`; each file
  remains an unmodified OpenMoji asset.

No OpenMoji artwork is presented as original project artwork.

## unDraw SVG Collection

The scene and reward illustrations in `assets/undraw/` are from the
[unDraw SVG Collection](https://github.com/balazser/undraw-svg-collection).

- License: MIT (included at `assets/undraw/LICENSE.txt`)
- Used for learning-scene hints and reward thumbnails.

## Noto Emoji

The SVG files in `assets/notoemoji/` are from Google's
[Noto Emoji](https://github.com/googlefonts/noto-emoji) project.

- License: [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0)
- SVG source: Google Fonts Noto Emoji static assets
- Used only in `vector-preview-v2.html` for visual comparison.

## Buzzphonics

The phoneme recordings in `audio/phonics/buzzphonics/` are from
[Buzzphonics](https://github.com/hellodeborahuk/buzzphonics) by Debbie Dann.

- License: MIT (included at `audio/phonics/buzzphonics/LICENSE.txt`)
- Files used: the `.m4a` phoneme recordings from `public/sounds/`
- Used for short letter and letter-group sounds during spelling practice.
